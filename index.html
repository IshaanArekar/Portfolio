Work

  • P-01 FitStackReal-time occupancy tracker running YOLOv4 on the GPU. dev Python · OpenCV · YOLOv4 · CUDA · Firebase · Angular · TypeScript
    Problem
    Knowing how many people are in a space right now, live, instead of counting by hand or guessing.
    What I built
    A people-counting pipeline that runs YOLOv4 through OpenCV's DNN module, keeps only person detections above 0.5 confidence, and uses non-maximum suppression to turn overlapping boxes into a stable count. It detects CUDA at runtime and moves inference to the GPU when one is present, falling back to CPU otherwise, so one code path runs anywhere. A background thread pool streams counts to Firebase Realtime Database for a live Angular dashboard.
    Security considerations
    Only the count goes to the cloud, not video frames, which keeps what leaves the machine to a single number.
    Outcome
    A live count on the dashboard with writes only on a count change or every 5 seconds, instead of every frame, so network I/O never blocks the capture loop.

    github ↗

  • P-02 ScanTapsPrivacy-first lost and found for ASU, using NFC and QR tags. both PWA · NFC · QR · Firebase · JavaScript · EPICS team of six
    Problem
    ASU's Tempe campus has 55,500+ people across a mile-wide campus, and lost and found ran on manual intake and record-keeping, with no verified way to claim an item.
    What I built
    As budget lead on a six-person EPICS team, I owned the project budget and hardware (NFC tags, cards and fobs). The team built a Progressive Web App: tap an NFC tag or scan a QR code on an item and a page opens that connects the finder and the owner, on any phone.
    Security considerations
    Designed around privacy: signed tokens in tag URLs instead of personal data, owner sign-in through ASU credentials, finder and owner contact details hidden from each other, no personal info in logs, rate limits against spam, and an audit trail of staff actions.
    Outcome
    Stage 1 shipped: a working PWA with NFC and QR across Android, iOS and desktop, and an encrypted database designed and tested.

    live ↗ github ↗

  • P-03 VITRA automationPython tooling for vendor IT risk assessments at ASU. sec Python · ServiceNow · compliance · work project
    Problem
    Vendor IT risk assessments were tracked by hand in spreadsheets, so missing vendor documents and overdue reassessments were easy to miss.
    What I built
    Internal Python tooling that pulls vendor and control data from ServiceNow, runs scripted checks that flag missing documentation and overdue reassessments, and generates status reports.
    Security considerations
    It handles internal vendor-risk data, so the code and data stay inside ASU and nothing from it is published here.
    Outcome

  • P-04 Flask Blog PlatformMulti-user blogging app with full authentication. dev Python · Flask · SQLAlchemy · Jinja2 · SQLite · bcrypt
    Problem
    A multi-user content app needs real authentication and a structure that stays maintainable as it grows.
    What I built
    A Flask app built on the application factory pattern with four blueprints (users, posts, main, errors). A one-to-many user-to-post model in SQLAlchemy, paginated feeds, per-author pages, and profile image upload with resizing.
    Security considerations
    bcrypt password hashing, Flask-Login sessions, and time-limited password reset tokens signed with itsdangerous and sent over Flask-Mail. Custom 403, 404 and 500 pages so users never see raw errors.
    Outcome
    Routes, forms and handlers stay modular and can be tested separately.

  • P-05 Weather Desktop ClientPyQt5 desktop app on the OpenWeatherMap API. dev Python · PyQt5 · REST APIs · python-dotenv
    Problem
    A desktop client for a third-party API has to handle every way the network or the API can fail.
    What I built
    A PyQt5 GUI that queries the OpenWeatherMap REST API and shows temperature, conditions and an icon mapped from the response's condition code.
    Security considerations
    The API key is loaded from environment variables, so no secret ever lands in source control.
